# Homestay The Myrtle - Landing Page

## VI - Giới thiệu

Trang web này được xây dựng hoàn toàn bằng AI trong một buổi chiều ngẫu hứng. Từ ý tưởng ban đầu, thiết kế giao diện, viết code cho đến deploy lên GitHub Pages — tất cả đều được thực hiện thông qua cuộc trò chuyện với Claude (Anthropic AI).

Không framework, không build tool, không phức tạp. Chỉ là HTML, CSS, JavaScript thuần túy và một chút cảm hứng từ Đà Lạt.

## EN - Introduction

This website was built entirely with AI during a spontaneous afternoon session. From the initial concept, UI design, coding, to deploying on GitHub Pages — everything was done through a conversation with Claude (Anthropic AI).

No frameworks, no build tools, no complexity. Just pure HTML, CSS, JavaScript, and a little inspiration from Dalat.
